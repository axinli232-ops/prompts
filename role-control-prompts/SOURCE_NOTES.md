# Source notes

`data/prompts.jsonl` preserves source type, source label, and URL for each selected system prompt. Source metadata describes the selection history and has not been independently re-audited against every upstream full prompt during this export.

- `此前USENIX论文原文`: style prompt attributed to Appendix A of the cited USENIX paper.
- `网站完整原文`: complete short prompt attributed to prompts.chat.
- `长prompt中的原句摘录`: verbatim selected sentence(s) from a longer prompts.chat entry; not the entire original prompt and not a claim of full functional equivalence.

Query text is AI-generated synthetic input. There are no gold answers, response labels, model outputs, or claims of independent benchmark validation.

Notion URLs in metadata identify the source snapshots used for this export; they may require account access. They do not confer access to those pages.
